## Finding #11 — 🟡 MEDIUM

**Rule:** R-05 — Visual Inconsistency (Border Radius)  
**Page/Component:** Seluruh aplikasi  
**Issue:** Sistem `border-radius` tidak konsisten antar halaman — campuran `rounded-none`, `rounded-md`, `rounded-lg`, `rounded-xl` tanpa pola yang jelas  
**Evidence:**
```
whatsapp/page.tsx   → rounded-none (flat design)
copilot/page.tsx    → rounded-none untuk input/tombol, rounded-xl untuk card
inventory/page.tsx  → rounded-xl untuk stat card, rounded-md untuk tombol
dashboard/page.tsx  → rounded-lg, rounded-md
settings/page.tsx   → rounded-xl, rounded-2xl untuk modal, rounded-lg untuk input
```
`globals.css` mendefinisikan `--radius: 0.5rem` dan token `radius-sm/md/lg/xl` tapi tidak dipakai secara konsisten. Token sudah ada — hanya penggunaannya yang kacau.
